# claude-project-onboarder

Skill Claude Code pour l'onboarding complet de projets — pipeline en 8 steps (git init, indexation, stack eval, CLAUDE.md, env setup, README, commit).

## Getting Started

### Prerequisites

- [Claude Code](https://docs.anthropic.com/en/docs/claude-code) installé
- `git`, `gh` (GitHub CLI), `bun` disponibles dans le PATH

### Install

```bash
git clone git@github.com:fanilosendrison/claude-project-onboarder.git
cd claude-project-onboarder
bash install.sh    # crée un symlink dans ~/.claude/skills/
```

### Usage

Dans Claude Code, sur n'importe quel projet :

```
/claude-project-onboarder
```

Ou variantes : `setup le projet`, `onboard project`, `prépare le projet`.
